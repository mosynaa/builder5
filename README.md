# Allegato A Builder · SOMO — v18

Builder statico per creare Allegati A SOMO in PDF e DOCX.

## Logica v18

Il builder resta generale e intuitivo: scegli tipologia cliente, obiettivi, servizi, produzione, quantità, formule, compensi ed eventuale TikTok Shop. Il documento finale usa invece una struttura unica e ordinata, coerente con gli Allegati A SOMO di Horizon / 9 Gradi.

Struttura del documento: **Oggetto → Sintesi dell'offerta → Obiettivo → Servizi inclusi → Produzione / modello di produzione → Compenso → eventuale dettaglio Meta Ads → eventuale dettaglio TikTok Shop → Ulteriori extra → Pagamento e validità → Formula prescelta / firma**.

### Novità principali

- **Proposta Basic**, **TikTok Shop**, **Basic + TikTok Shop**;
- formula singola oppure **2 formule alternative** anche quando viene aggiunto TikTok Shop;
- in **Basic + TikTok Shop**, TikTok Shop compare come **colonna autonoma** nella sintesi;
- i valori di produzione vengono inseriti una volta e riutilizzati coerentemente in tutte le sezioni;
- obiettivo e testo della produzione si adattano alla tipologia cliente (retail, emporio, food, wellness, B2B, ecc.);
- gli **obiettivi consigliati sono già selezionati** in base alla tipologia cliente e cambiano anche le diciture visibili nel builder; restano sempre modificabili;
- nuova tendina **Stile del testo**: Professionale, Semplice o Molto sintetico; per gli empori viene suggerito Semplice, ma la scelta resta sempre modificabile;
- lo stile cambia il linguaggio di obiettivi, servizi, produzione, Meta Ads e TikTok Shop senza modificare quantità, servizi o compensi;
- attività deselezionate rimosse anche dai testi correlati;
- autocompletamento clienti ricorrenti, incluso Horizon;
- PDF su due pagine A4 con spazi distribuiti;
- anteprima mobile leggibile con scorrimento della sola tabella quando le colonne sono molte;
- DOCX con loghi incorporati, colori e formattazione diretta per una migliore compatibilità con Word e Google Docs;
- data sempre vuota da compilare a penna.

## Pubblicazione GitHub Pages

Caricare nella root del repository `index.html`, `styles.css`, `app.js`, `README.md` e la cartella `assets`. Dopo la sostituzione dei file effettuare un hard refresh (`Cmd + Shift + R`).


## v18 – preset obiettivi per tipologia cliente
Ogni tipologia cliente carica un set di obiettivi realmente dedicato e già selezionato. Le diciture e le azioni usate nel documento seguono il preset del settore; le spunte restano sempre modificabili.
